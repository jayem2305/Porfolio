# Portfolio

Personal portfolio site for Jhon Mark Enrique, built with [Next.js](https://nextjs.org) and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

Content (bio, skills, projects, contact links) lives in `src/lib/data.ts` — edit that file to update the site.

## Deploy

This project deploys to [Vercel](https://vercel.com) with zero configuration: import the repository in the Vercel dashboard and it will detect Next.js automatically.
